# Agent_Updates

Signed, contract-valid agent updates live here, one dated directory per
day: `YYYY-MM-DD/YYYY-MM-DD HHMM - <project> - <lane> - <agent>.md`.

The contract is enforced by `gf intake-update`; see
`040 Agent Instructions/closeout-contract.md`. Drafts that don't validate
yet belong in `010 Inbox/Agent Raw Notes/`.
